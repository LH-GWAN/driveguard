# 시연 시나리오

심장 질환 이력이 있는 운전자 A가 동승자 C와 장거리를 가는 가상 상황 하나입니다. 보호자는 가족 B입니다. 전부 가상 데이터이며 Pleos Connect 에뮬레이터 결과입니다. 시나리오가 구조나 응급 대응의 성공을 뜻하지 않습니다.

## 준비

```bash
cd guardian-mock && npm start
```

```bash
scripts/vc.sh session
```

음성 입력이 필요한 장면은 debug 빌드로 진행합니다. 호스트 마이크는 켜지 않습니다.

## 녹화 주의

- 화면에 없는 소리와 동작은 자막으로 구분합니다. 음성 안내 문구는 자막으로 씁니다.
- 구조 화면은 `FLAG_SECURE` 때문에 `adb screencap`이 빈 화면입니다. `adb emu screenrecord`를 씁니다.
- 비상등, 후방 안개등, 에어백, 119 자동 신고를 보여 주거나 말하지 않습니다. 앱이 하는 일은 "멈춤 후 응답 확인"으로 설명합니다.
- 제조사 정차 기능이 차를 P로 둔다고 말하지 않습니다.
- 사용자 폴더 경로, 계정, 실명, 실제 연락처가 화면에 나오지 않게 합니다.

# 시연 시나리오

심장 질환 이력이 있는 운전자 A가 동승자 C와 장거리를 가는 가상 상황 하나입니다. 보호자는 가족 B입니다. 전부 가상 데이터이며 Pleos Connect 에뮬레이터 결과입니다. 시나리오가 구조나 응급 대응의 성공을 뜻하지 않습니다.

## 준비

```bash
cd guardian-mock && npm start
```

```bash
scripts/vc.sh session
```

음성 입력이 필요한 장면은 debug 빌드로 진행합니다. 호스트 마이크는 켜지 않습니다. 합성 음성 파일은 `help`("가슴이 아파요"), `ok`("괜찮아요"), `cancel`("괜찮아 취소해줘"), `end`("안내 종료")입니다.

## 녹화

- 자막은 장면에서 일어나는 일을 짧게 적습니다. 앱이 말하는 문장은 "음성 안내:"로 적습니다.
- 누른 컨트롤은 앱의 보라색으로 채워 보여 줍니다. 녹화 스크립트가 누른 시각과 버튼 경계(uiautomator bounds)를 남기고, 영상 빌드가 누른 순간의 화면을 0.8초 멈춘 뒤 그 버튼 모양대로 반투명 보라색을 칠합니다. 글자는 비쳐 읽힙니다. 체크박스와 입력칸은 칠하지 않고 체크되거나 선택된 직후의 실제 화면을 멈춰 보여 줍니다. 권한 대화상자는 누르기 전에 잠깐 멈추고 실제로 무슨 권한인지 자막으로 적습니다. 시스템 창 이름과 실제 권한이 다릅니다: '위치 정보' 창은 차량 속도(`android.car.permission.CAR_SPEED`, 위치 그룹), '알 수 없는 작업' 창은 Pleos 차량 위치(`pleos.car.permission.FUSED_LOCATION`, 그룹 없음)입니다. 앱은 이 창들 앞에 권한 안내 화면을 보여 줍니다.
- 에뮬레이터 녹화의 소리는 소리가 날 때만 기록되어 중간이 비어 있습니다. 영상 빌드는 녹화 시각대로 무음을 채워(`aresample=async=1:first_pts=0`) 대사가 해당 장면에 나오게 합니다. 멈춤이 대사 도중에 걸리면 멈춤을 대사 시작 직전으로 옮겨 소리를 자르지 않습니다. 녹화를 멈췄다 다시 켜는 사이의 소리는 남지 않으므로, 대사가 이어지는 3·4번 장면은 한 번에 녹화합니다. 기어 변경 같은 차량 효과음은 장면 첫머리에 걸리지 않게 녹화 전에 처리합니다.
- 에뮬레이터 녹화(`adb emu screenrecord`)의 앱 음성은 부하에 따라 짧은 끊김과 광대역 순간음이 섞여 '팍' 하고 튑니다(대사 첫 1~2초에 몰림). 그래서 소리는 에뮬레이터 오디오 출력을 QEMU 모니터의 `wavcapture`로 받은 WAV에서 가져옵니다. 에뮬레이터를 `emulator ... -qemu -monitor telnet:127.0.0.1:<포트>,server,nowait`로 띄우고 `DG_QEMU_MONITOR=<포트> DG_EMU_WAV=<파일>`을 주고 녹화하면, `scripts/clean_audio.py`가 녹화의 소리 구간마다 같은 소리를 WAV에서 상호상관으로 찾아 녹화 시각에 놓고, 출력 자체에 있는 1ms 안팎의 끊김(언더런)은 `scripts/fix_audio.py`로 메웁니다. 찾지 못한 구간만 녹화 소리를 씁니다. (`-audio wav` 백엔드도 같은 소리를 주지만 음성 인식이 수 초 느려져 쓰지 않습니다.)
- 튐 검사는 `scripts/check_pops.py <영상>`입니다. 앱 음성은 약 11kHz 위에 소리가 없으므로 11.5~16kHz 순간 에너지가 대사 크기 대비 -55dB를 넘는 2.7ms 창이 100ms 안에 15개 이상이면 튐 구간으로 셉니다. 인식 알림음 같은 시스템 효과음은 실제로 높은 배음이 있어 걸리므로 앱 대사 구간에만 적용합니다. 소리는 키운 뒤 큰 차량 효과음(문 잠금 해제음)만 리미터로 누르고, 자동 레벨은 꺼서 AAC 변환 뒤 1을 넘지 않게 합니다.
- 화면에 없는 기능을 있다고 말하지 않고, 실차에서 동작했다고 말하지 않습니다.
- 차량 값은 Virtual Console, 위치는 에뮬레이터, 운전자의 말은 합성 음성 파일로 넣습니다(debug 빌드). 이 구분은 이 문서와 README에 적습니다.
- 녹화하는 동안에는 내비 앱의 길 안내 음성이 앱 안내 음성과 겹쳐 대사가 묻히므로 내비 음량 그룹을 0으로 둡니다(`cmd car_service set-group-volume 0 1 0`). 녹화가 끝나거나 중간에 멈추면 기본값으로 돌립니다(`set-group-volume 0 1 45`, 이 명령의 눈금에서 45가 기본 20단계). 앱 음성은 이 그룹을 쓰지 않습니다.
- 구조 화면은 `FLAG_SECURE` 때문에 `adb screencap`이 빈 화면입니다. `adb emu screenrecord`를 씁니다.
- 비상등, 후방 안개등, 에어백, 119 자동 신고를 보여 주거나 말하지 않습니다. 앱이 하는 일은 "멈춤 후 응답 확인"입니다.
- 사용자 폴더 경로, 계정, 실명, 실제 연락처가 화면에 나오지 않게 합니다.

# 보안 점검

프로토타입 기준입니다. "확인"은 에뮬레이터와 로컬 가상 서버에서 본 결과입니다.

| 항목 | 상태 | 근거 |
|---|---|---|
| 건강 정보 암호화 저장 | 충족 | Android Keystore AES-256-GCM. `no_backup/profile.enc`에 암호문만 있음을 앱 폴더 검색으로 확인 |
| 건강 정보 평소 가림 | 충족 | 구조 단계에서만 화면에 표시. 메인 화면은 "저장됨 (가려짐)"만 표시. 사전 입력 화면은 운전자가 수정할 때 표시 |
| 민감정보 별도 동의 | 충족 | 건강 정보, 위치 전송, 보호자 동의를 각각 받음 |
| 앱 밖으로 병력을 보내지 않음 | 충족 | 전송 객체에 건강 정보 필드가 없고, 단위 테스트로 필드와 문구를 고정. 가상 서버도 정해진 필드만 저장 |
| 의료기관 전송 없음 | 충족 | 전송 경로는 로컬 가상 서버뿐 |
| 로그에 민감정보 없음 | 확인 | 앱 로그는 상태 이름과 결과 코드뿐. 인식 문장을 기록하지 않음. logcat 검색 0건 |
| 자동 백업 비활성 | 충족 | `allowBackup=false`, 백업 제외 폴더 사용 |
| 화면 캡처 방지 | 보조 | 사전 입력과 구조 화면에 `FLAG_SECURE`. 에뮬레이터 자체 녹화와 외부 카메라는 막지 못함 |
| 디버그 비활성 | 충족 | release 빌드, debuggable 없음 |
| 시험 훅 분리 | 충족 | 합성 음성 주입은 debug 소스셋에만 있고 release APK에 해당 클래스와 음성 파일이 없음 |
| 서명 키 저장소 밖 | 충족 | 키와 `keystore.properties`는 저장소에 없음. App Market 배포 인증서는 아님 |
| 비밀값 검사 | 확인 | `scripts/check_secrets.py`로 작업 트리, 이력, APK, 영상 검사. 커밋 전 훅으로 실행 |
| 실제 병력·연락처 미사용 | 충족 | 저장소, APK, 영상의 값은 모두 가상 |
| 잠금 해제 조건 | 충족 | 응답 없음을 거치고 속도 0, 기어 P일 때만. 상태 기계와 제어 계층 양쪽에서 확인 |
| 앱이 다시 잠그거나 창문을 닫지 않음 | 충족 | 구조자가 막히거나 끼이지 않도록 호출하지 않음 |
| 보호자 원격 종료 없음 | 충족 | 종료는 차 안의 화면이나 음성으로만 |
| 운전자 변경 | 부분 | 끄기와 재확인, 정보 삭제만 있음. 사전 입력 정보를 인증으로 보호하지 않음 |
| **전송 TLS** | **미충족** | 가상 서버는 로컬 평문 HTTP이며 `10.0.2.2`에만 허용. 실제 전송 경로를 정할 때 TLS 1.2 이상 필요 |
| 가상 서버 데이터 | 해당 없음 | 메모리에만 저장, 루프백에서만 수신, 본문 비로그 |

## 잠금 해제의 남은 위험

문이 풀린 차에 응답 없는 운전자가 남으면 범죄 위험이 생깁니다. 누가 기어를 P로 넣었는지 앱은 구분하지 못합니다. 실서비스 전에 별도 안전 검토가 필요합니다.

## 권한

`pleos.car.permission.CAR_DOORS`, `CONTROL_CAR_DOORS`, `CAR_LIGHTS`, `CONTROL_CAR_LIGHTS`, `CAR_WINDOWS`, `CONTROL_CAR_WINDOWS`, `CAR_DRIVE`, `TTS_SERVICE`, `STT_SERVICE`, `NAVI_ROUTE_SEARCH`, `FUSED_LOCATION`, `android.car.permission.CAR_SPEED`, `CAR_POWERTRAIN`, `android.permission.RECORD_AUDIO`, `POST_NOTIFICATIONS`, `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE`, `INTERNET`.

앱 리뷰 가이드는 차량 상태를 바꾸는 SDK·API에 별도 심사 기준을 적용하고, Vehicle SDK 퍼미션은 App Market과 사전 협의·승인된 경우에만 선언할 수 있다고 안내합니다. **승인 가능성은 확인하지 못했습니다.**

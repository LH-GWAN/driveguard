# 검증 결과

확인일 2026-11-08. 환경: Pleos Connect Emulator v2.1.0 (API 34, arm64), Cold boot, Apple Silicon Mac. 차량 값은 Virtual Console, 위치는 `adb emu geo fix` 또는 AVD 값입니다. **에뮬레이터 결과이며 실차 동작을 보장하지 않습니다. App Market 승인은 확인하지 못했습니다.** 응답 확인의 오탐·미탐 성능은 측정하지 않았습니다.

SDK: Vehicle 2.3.2, NaviHelper 3.0.5, FusedLocation 1.1.3, TextToSpeech 3.3.1, SpeechToText 3.3.1.

## 자동 시험

아래 숫자는 현재 빌드(커밋 bdc7508 이후, 취소 문구 "괜찮아 취소해줘"와 119 신고 요청 반영) 기준입니다.

|---|---|
| 앱 단위 테스트 (`./gradlew :app:testDebugUnitTest`) | 76건 통과 |
| 가상 서버 테스트 (`cd guardian-mock && npm test`) | 10건 통과 |

| release APK AVD 재연 (`scripts/e2e_release.py`) | 35건 통과. 음성 입력 제외 |

## 차가 다시 움직일 때

| 경우 | 결과 |
|---|---|
| 응답 없음 뒤 3초 이상 계속 움직임 | 잠금 해제 흐름을 멈춤. 음성 안내, 보호자에게 "다시 움직임" 전달, 취소 메시지 없음 |
| 그 뒤 기어 P로 세움 | 잠금을 풀지 않음 |

## 재현되지 않은 관찰 2건

취소 규칙 수정 뒤의 재연에서는 둘 다 재발하지 않았습니다. 원인은 찾지 못했습니다.

- 재연 뒤 앱 프로세스가 사라져 흐름이 시작되지 않은 경우가 1회 있었습니다(첫 구현 빌드). 로그를 지운 뒤라 원인을 알 수 없습니다. 이후 11분 유지 시험과 재연(취소 규칙 수정 빌드의 debug 96건, 현재 빌드의 debug 103건과 release 35건)에서는 같은 프로세스로 끝나 재발하지 않았습니다. 서비스를 다시 시작하도록 하고(`START_STICKY`) 다음 시작 때 이유 코드를 남깁니다.
- 재연 중 "방향지시등 취소" 1건이 실패했습니다(첫 구현 빌드). 따로 4회와 이후 빌드의 전체 재연 3회에서는 통과했습니다.

## 서비스가 화면을 띄우는 동작

기어 P가 된 뒤 서비스가 앱 화면을 띄우는 동작은 실행마다 달랐습니다. 최근 두 번의 녹화에서는 화면이 떠서 자막에 그대로 적었고, 그 전 녹화에서는 뜨지 않았습니다. 그래서 앱을 여는 음성 안내를 기본 경로로 둡니다.

## 시험하지 못한 것

실제 마이크 음성 인식(Mac 마이크를 켜야 해서 하지 않음. 에뮬레이터 호스트 마이크는 끈 채로 시험), 다른 사람이 "괜찮아 취소해줘"라고 말하는 경우, 스피커 안내 음성이 마이크로 들어가는 경우, 실제 차량에서 브레이크를 밟고 기어를 P로 넣는 순서, 주행 중 호출을 시작하는 방법(미정), 실제 보호자 전송 경로와 TLS, 시동 시 자동 시작, 긴 시간 유지, 실차, 오탐·미탐 성능, 네트워크가 없는 상황에서 실제 경로의 동작, App Market 승인, 제조사 정차 기능과의 관계.

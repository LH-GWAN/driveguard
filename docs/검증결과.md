# 검증 결과

확인일 2026-11-08. 환경: Pleos Connect Emulator v2.1.0 (API 34, arm64), Cold boot, Apple Silicon Mac. 차량 값은 Virtual Console, 위치는 `adb emu geo fix` 또는 AVD 값입니다. **에뮬레이터 결과이며 실차 동작을 보장하지 않습니다. App Market 승인은 확인하지 못했습니다.** 응답 확인의 오탐·미탐 성능은 측정하지 않았습니다.

SDK: Vehicle 2.3.2, NaviHelper 3.0.5, FusedLocation 1.1.3, TextToSpeech 3.3.1, SpeechToText 3.3.1.

## 자동 시험

## 시나리오 재연 (앱이 뒤에 있는 상태)

| 단계 | 결과 | 근거 |
|---|---|---|
| 주행 중 도움 요청 (D 30 km/h) | 동작 | 합성 음성 "가슴이 아파요" → 인식 → 안내 음성 → 내비 경로(공공데이터 좌표) → 취소 없으면 가상 위치 전송 |
| 멈춘 뒤 응답 확인 | 동작 | D, 속도 0, 무조작 대기 후 질문 2회, 두 번째 뒤 응답 없음 |
| 응답 없음 | 동작 | 가상 서버에 위치·정차 시각 도착, 창문 콘솔 값 0→20, 동승자 안내 음성. 잠금·조명 호출 없음 |
| 기어 P 이후 | 동작 | 고지와 취소 시간 뒤 콘솔 값: 잠금 해제, 실내등 켜짐, 미등(`Position`). 글러브박스는 SDK 응답만 확인 |
| 구조 화면 | 동작 | 구조 단계에서만 입력값 표시. 앱을 여는 조작은 시험 도구가 대신함 |
| 종료 | 동작 | 화면·음성 "종료" 모두 동작, 건강 정보 다시 가림, 가상 종료 전달 |

## 그 밖의 확인

| 항목 | 결과 | 근거 |
|---|---|---|
| 포그라운드 서비스 유지 | 11분 유지 | 앱이 뒤에 있는 채 같은 프로세스 유지, 이후 전체 흐름 동작. 더 긴 시간은 미확인 |
| 가상 서버가 꺼졌을 때 | 동작 | 재시도 3회 뒤 실패 기록과 음성 고지. 창문과 다음 단계는 계속 진행 |
| 건강 정보 암호화 | 확인 | 앱 폴더에 평문 검색 0건, `profile.enc`만 있음 |
| logcat 평문 | 확인 | 병력, 복용약, 보호자 이름·번호 0건 |
| release APK | 확인 | 합성 음성 주입 불가, 시험 훅과 음성 파일 없음 |
| 음성 출력 | 일부 확인 | TTS 완료 콜백, 에뮬레이터 녹화 오디오에서 질문 구간에만 소리가 있음. 내용을 귀로 듣지는 못함 |

## 재현되지 않은 관찰 2건

- 재연 뒤 앱 프로세스가 사라져 흐름이 시작되지 않은 경우가 1회 있었습니다. 로그를 지운 뒤라 원인을 찾지 못했습니다. 이후 11분 유지 시험과 재연에서는 재발하지 않았습니다. 다음 시작 때 이유 코드를 남기도록 했습니다.
- 재연 중 "방향지시등 취소" 1건이 실패했습니다. 같은 시험을 4회 따로 돌리고 전체 재연을 다시 돌렸을 때는 모두 통과했습니다. 원인은 찾지 못했습니다.

## 시험하지 못한 것

실제 마이크 음성 인식(Mac 마이크를 켜야 해서 하지 않음. 에뮬레이터 호스트 마이크는 끈 채로 시험), 실제 보호자 전송 경로와 TLS, 시동 시 자동 시작, 긴 시간 유지, 실차, 오탐·미탐 성능, 네트워크가 없는 상황에서 실제 경로의 동작, App Market 승인, 제조사 정차 기능과의 관계.
